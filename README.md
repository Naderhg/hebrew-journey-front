# Hebrew Journey – نبذة عن الموقع

**Hebrew Journey** هو موقع تعليمي يهدف إلى تسهيل إدارة عملية تعلم اللغة العبرية، من خلال توفير مكان واحد يجمع الطلاب والمعلمين وفريق العمل.

يقدم الموقع خدمات مختلفة لكل فئة:

- **الطلاب:** يمكنهم الاشتراك في الدورات، وحضور الدروس، وحل الواجبات والاختبارات، ومتابعة مستواهم وتقدمهم التعليمي.
- **المعلمون:** يمكنهم متابعة طلابهم، وإدارة الدروس والواجبات والاختبارات، وتنظيم المواعيد وتسجيل الحضور.
- **الإدارة:** يمكنها إدارة الطلاب والمعلمين والدورات والاشتراكات والمدفوعات وتنظيم العمل داخل المنصة.
- **فريق المبيعات:** يمكنه متابعة العملاء المهتمين بالدراسة، والتواصل معهم، ومتابعة الاشتراكات والمبيعات.
- **فريق الدعم:** يمكنه مساعدة الطلاب، والرد على استفساراتهم، ومتابعة مشكلاتهم وتنظيم التواصل معهم.

بشكل عام، يهدف الموقع إلى **تنظيم العملية التعليمية بالكامل، وتسهيل التواصل بين الطلاب والمعلمين والإدارة، وتوفير تجربة تعليمية سهلة ومنظمة من خلال منصة واحدة.**
